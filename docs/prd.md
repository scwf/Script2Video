## 1. PRD ——《AI 口播配图自动短视频生成器》

### 1.1 背景
- 市面上短视频生产对人力依赖大：脚本撰写、配图、配音、剪辑同步等环节繁琐。  
- 目标用户：内容运营、教育培训、自媒体、品牌营销等需要批量生产图文解说视频的团队 / 个人。  
- 本产品希望 **端到端** 自动完成 “脚本 → 配图 → 配音 → 剪辑 → 成片” 流程，首发版本聚焦 **静态配图 + 旁白** 场景，风格以「吉卜力温暖插画」为默认视觉模板。

### 1.2 目标
| 维度 | 必须 (v1) | 可选 (v2+) |
| ---- | --------- | ---------- |
| 产出 | 1080p MP4；画面与语音 100 % 同步 | 多分辨率 / 竖屏 |
| 自动化 | 一键上传文字稿即可 | Web UI 批量队列 |
| 成本 | 便携笔记本电脑可运行 | 提供云端服务运行 |
| 质量衡量 | 画面-文本匹配度  | 每个分段画面由AI生成的图片转为AI生成的视频，进一步提高视频质量 |

### 1.3 核心用户故事
1. **UG-1**：运营小王上传一段 600-字脚本，5 分钟后下载到配音配图成片，直接投放公众号。  
2. **UG-2**：培训讲师批量导入 10 篇课程节要，系统生成 10 条教学视频并按章节编号。  
3. **UG-3**：品牌团队切换“水彩”视觉模板，再生成同一脚本的 AB 测试版本。

### 1.4 功能需求
| # | 功能 | 说明 |
| - | ---- | ---- |
| F-1 | 文稿智能分段 | 调用gemini、claude、deepseek大模型实现，段落 < 200 字，自动编号 |
| F-2 | 图像提示词生成 | 调用gemini、claude、deepseek大模型实现，提取主题/场景/情感，默认 Ghibli 风格，可选风格 override |
| F-3 | AI 生图 | Stable Diffusion XL，本地或云端；命名遵循 `img_<index>.png` |
| F-4 | 高质量 TTS | 可选 Minimax / Google / Azure / ElevenLabs；情感参数随段落情绪 |
| F-5 | 片段合成 | 每段图 + 音频 → MP4 (`seg_<index>.mp4`)；淡入淡出 0.5 s |
| F-6 | 全片拼接 | `concat` 按 1-N 顺序；输出 `final.mp4` |
| F-7 | 任务编排 & 日志 | Python pipeline；失败重试、GPU 占用监控 |
| F-8 | 下载与预览 | Web/API 返回链接；保留 7 天 |

### 1.5 非功能需求
- **稳定性**：批量 50 条脚本成功率 ≥ 98 %  
- **扩展性**：模块化（NLP / Diffusion / TTS / FFmpeg）可横向扩容
